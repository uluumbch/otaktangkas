# 🔧 Phase 0: Environment Setup

> **Duration**: 1-2 days  
> **Goal**: Set up development environment with all required tools and dependencies

## 📋 Overview

This phase establishes the development foundation for OtakTangkas. We'll install Laravel 13, configure all dependencies, and prepare the project structure.

---

## ✅ Prerequisites

### System Requirements

```bash
# Required versions
PHP >= 8.3 (8.4 recommended; 8.5 supported)
Composer >= 2.8
Node.js >= 22.0 (LTS)
npm >= 10.0
MySQL >= 8.4 (LTS) or PostgreSQL >= 16
Redis >= 7.0 (optional but recommended)
```

### Development Tools

- **IDE**: VS Code, PHPStorm, or Sublime Text
- **Terminal**: Terminal app with bash/zsh
- **Git**: Version control
- **Postman/Insomnia**: API testing (optional)

### Third-Party Accounts

1. **Real-time**: No account needed! We use **Laravel Reverb**, the first-party self-hosted WebSocket server (free, runs alongside the app)

2. **Google Analytics** (Phase 7)
   - Set up property at https://analytics.google.com

> **Note:** PropellerAds/Adsterra publisher accounts are only needed for Phase 6 (Monetization), which is **deferred to post-MVP** — skip them for now.

## 🚀 Installation Steps

### Step 1: Create the Laravel 13 Application

```bash
# Install the Laravel installer (if not already installed)
composer global require laravel/installer

# Create a new Laravel 13 app with the official Livewire starter kit
# (provides authentication scaffolding — login, registration, password reset)
laravel new otaktangkas --using=laravel/livewire-starter-kit
cd otaktangkas

# Or run `laravel new otaktangkas` and pick "Livewire" when prompted

# Initialize git and create development branch
git init
git checkout -b feature/otaktangkas-mvp
```

### Step 2: Install PHP Dependencies

```bash
# Install additional Composer dependencies
composer require filament/filament livewire/livewire spatie/laravel-permission

# Install Reverb + broadcasting scaffolding (config, Echo bootstrap, .env keys)
php artisan install:broadcasting
```

**Key Dependencies:**
- `laravel/framework`: ^13.0
- `livewire/livewire`: ^4.0
- `filament/filament`: ^5.0
- `laravel/reverb`: ^1.0 (first-party WebSocket server)
- `spatie/laravel-permission`: ^6.9

### Step 3: Install JavaScript Dependencies

```bash
# Install npm packages
npm install

# Key packages:
# - tailwindcss + @tailwindcss/vite (Tailwind CSS 4)
# - vite
# - laravel-echo
# - pusher-js (client library — Reverb speaks the Pusher protocol)
# Note: Alpine.js is bundled with Livewire 4 — no separate install needed
```

### Step 4: Environment Configuration

```bash
# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate
```

**Edit `.env` file:**

```env
# Application
APP_NAME="OtakTangkas"
APP_ENV=local
APP_KEY=base64:...  # Generated by artisan key:generate
APP_DEBUG=true
APP_TIMEZONE=Asia/Jakarta
APP_URL=http://localhost:8000
APP_LOCALE=id
APP_FALLBACK_LOCALE=en

# Database
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=otaktangkas
DB_USERNAME=root
DB_PASSWORD=your_password

# Reverb (Real-time, self-hosted — keys generated by `php artisan install:broadcasting`)
BROADCAST_CONNECTION=reverb
REVERB_APP_ID=your_app_id
REVERB_APP_KEY=your_app_key
REVERB_APP_SECRET=your_app_secret
REVERB_HOST="localhost"
REVERB_PORT=8080
REVERB_SCHEME=http

VITE_REVERB_APP_KEY="${REVERB_APP_KEY}"
VITE_REVERB_HOST="${REVERB_HOST}"
VITE_REVERB_PORT="${REVERB_PORT}"
VITE_REVERB_SCHEME="${REVERB_SCHEME}"

# Queue (Redis recommended)
QUEUE_CONNECTION=redis

# Cache (Redis recommended)
CACHE_STORE=redis
SESSION_DRIVER=redis

# Redis
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

# Mail (for notifications)
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@otaktangkas.com"
MAIL_FROM_NAME="${APP_NAME}"

# Filament (Admin Panel)
FILAMENT_DOMAIN=admin.otaktangkas.test
```

### Step 7: Build Frontend Assets

```bash
# Development build (with hot reload)
npm run dev

# Production build (optimized)
npm run build
```

### Step 8: Start Development Server

```bash
# Terminal 1: Application server
php artisan serve

# Terminal 2: Reverb WebSocket server (real-time)
php artisan reverb:start

# Terminal 3: Queue worker
php artisan queue:work

# Terminal 4: Vite dev server (if using npm run dev)
npm run dev

# Tip: `composer run dev` in Laravel 13 starts serve + queue + vite together
```

Visit: http://localhost:8000

## ⚙️ Configuration Files

### Tailwind CSS Configuration

Tailwind CSS 4 uses **CSS-first configuration** — there is no `tailwind.config.js`. All customization lives in `resources/css/app.css` via the `@theme` directive.

**File**: `resources/css/app.css`

```css
@import 'tailwindcss';

/* Scan non-default template locations (Blade views are detected automatically) */
@source '../../vendor/laravel/framework/src/Illuminate/Pagination/resources/views/*.blade.php';
@source '../../vendor/filament/**/*.blade.php';

/* Official plugins load via @plugin */
@plugin '@tailwindcss/forms';

@theme {
    --font-sans: 'Figtree', ui-sans-serif, system-ui, sans-serif;

    /* OtakTangkas brand colors */
    --color-primary-50: #f0f9ff;
```

### Vite Configuration

**File**: `vite.config.js`

```javascript
import { defineConfig } from 'vite';

export default defineConfig({
    plugins: [

        }),

    ],

        },

```

### Laravel Echo Configuration

`php artisan install:broadcasting` generates this file automatically. Reverb speaks the Pusher protocol, so Echo uses the `pusher-js` client under the hood.

**File**: `resources/js/echo.js`

```javascript
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

window.Pusher = Pusher;

window.Echo = new Echo({
    broadcaster: 'reverb',
    key: import.meta.env.VITE_REVERB_APP_KEY,
    wsHost: import.meta.env.VITE_REVERB_HOST,
    wsPort: import.meta.env.VITE_REVERB_PORT ?? 80,
    wssPort: import.meta.env.VITE_REVERB_PORT ?? 443,
    forceTLS: (import.meta.env.VITE_REVERB_SCHEME ?? 'https') === 'https',
    enabledTransports: ['ws', 'wss'],
});
```

Update `resources/js/app.js`:

```javascript
import './bootstrap';
import './echo';

// Note: Alpine.js is bundled with Livewire 4 — do not import or start it manually
```

### Broadcasting Configuration

**File**: `config/broadcasting.php` (created by `php artisan install:broadcasting`)

Ensure Reverb is configured:

```php
'connections' => [
    'reverb' => [
        'driver' => 'reverb',
        'key' => env('REVERB_APP_KEY'),
        'secret' => env('REVERB_APP_SECRET'),
        'app_id' => env('REVERB_APP_ID'),
        'options' => [
            'host' => env('REVERB_HOST'),
            'port' => env('REVERB_PORT', 443),
            'scheme' => env('REVERB_SCHEME', 'https'),
            'useTLS' => env('REVERB_SCHEME', 'https') === 'https',
        ],
        'client_options' => [
            // Guzzle client options: https://docs.guzzlephp.org/en/stable/request-options.html
        ],
    ],
],
```

## 🧪 Testing Setup

### Pest Configuration

Laravel 13 ships with **Pest 4** as the default testing framework (PHPUnit remains available underneath). Pest reads the standard `phpunit.xml` for environment configuration.

**File**: `phpunit.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<phpunit xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:noNamespaceSchemaLocation="vendor/phpunit/phpunit/phpunit.xsd"
         bootstrap="vendor/autoload.php"
         colors="true">
    <testsuites>
        <testsuite name="Unit">
            <directory>tests/Unit</directory>
        </testsuite>
        <testsuite name="Feature">
            <directory>tests/Feature</directory>
        </testsuite>
    </testsuites>
    <source>
        <include>
            <directory>app</directory>
        </include>
    </source>
    <php>
        <env name="APP_ENV" value="testing"/>
        <env name="BCRYPT_ROUNDS" value="4"/>
        <env name="CACHE_STORE" value="array"/>
        <env name="DB_DATABASE" value="otaktangkas_test"/>
        <env name="MAIL_MAILER" value="array"/>
        <env name="QUEUE_CONNECTION" value="sync"/>
        <env name="SESSION_DRIVER" value="array"/>
        <env name="TELESCOPE_ENABLED" value="false"/>
    </php>
</phpunit>
```

### Run Tests

## 🐛 Common Issues & Solutions

### Issue: Port 8000 Already in Use

```bash
# Use different port
php artisan serve --port=8001

# Or find and kill process using port 8000
# On Linux/Mac:
lsof -ti:8000 | xargs kill -9

# On Windows:
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

### Issue: Reverb Connection Failed

1. Ensure the Reverb server is running: `php artisan reverb:start`
2. Verify `REVERB_*` and `VITE_REVERB_*` values in `.env` match
3. Rebuild assets after changing `VITE_*` vars (`npm run dev` / `npm run build`)
4. Check firewall isn't blocking port 8080 (WebSocket connections)

```bash
# Test broadcasting through Reverb
php artisan tinker
>>> broadcast(new App\Events\TestEvent());
```

### Issue: Node Modules Not Found

```bash
# Clear node modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

### Issue: Redis Connection Refused

```bash
# Start Redis
# On Linux/Mac:
redis-server

# On Mac with Homebrew:
brew services start redis

# Check if running:
redis-cli ping
```

### Issue: Database Connection Failed

1. Verify MySQL is running
2. Check database name, username, password in `.env`
3. Ensure database exists

```bash
# Create database manually
mysql -u root -p
CREATE DATABASE otaktangkas;
EXIT;
```

### Issue: Permission Denied on storage/

```bash
# Fix permissions (Linux/Mac)
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

# Or use current user
chmod -R 775 storage bootstrap/cache
```
