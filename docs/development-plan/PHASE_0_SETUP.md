# 🔧 Phase 0: Environment Setup

> **Duration**: 1-2 days  
> **Goal**: Set up development environment with all required tools and dependencies

## 📋 Overview

This phase establishes the development foundation for OtakTangkas. We'll install Laravel 11, configure all dependencies, and prepare the project structure.

---

## ✅ Prerequisites

### System Requirements

```bash
# Required versions
PHP >= 8.2
Composer >= 2.5
Node.js >= 18.0
npm >= 9.0
MySQL >= 8.0 or PostgreSQL >= 14
Redis >= 6.0 (optional but recommended)
```

### Development Tools

- **IDE**: VS Code, PHPStorm, or Sublime Text
- **Terminal**: Terminal app with bash/zsh
- **Git**: Version control
- **Postman/Insomnia**: API testing (optional)

### Third-Party Accounts

1. **Pusher Account** (Free tier available)
   - Sign up at https://pusher.com
   - Create new app
   - Note: App ID, Key, Secret, Cluster

2. **PropellerAds/Adsterra** (Phase 6)
   - Sign up at https://propellerads.com or https://adsterra.com
   - Get publisher credentials

3. **Google Analytics** (Phase 7)
   - Set up property at https://analytics.google.com

## 🚀 Installation Steps

### Step 1: Clone Repository

```bash
# Clone the repository
git clone https://github.com/uluumbch/tic-tac-toe-mp-livewire.git
cd tic-tac-toe-mp-livewire

# Create development branch
git checkout -b feature/otaktangkas-refactor
```

### Step 2: Install PHP Dependencies

```bash
# Install Composer dependencies
composer install

# If you need to update dependencies
composer update
```

**Key Dependencies:**
- `laravel/framework`: ^11.9
- `livewire/livewire`: ^3.4
- `filament/filament`: ^3.2
- `pusher/pusher-php-server`: ^7.2
- `spatie/laravel-permission`: ^6.9

### Step 3: Install JavaScript Dependencies

```bash
# Install npm packages
npm install

# Key packages:
# - tailwindcss
# - alpinejs
# - vite
# - laravel-echo
# - pusher-js
```

### Step 4: Environment Configuration

```bash
# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate
```

**Edit `.env` file:**

```env
# Application
APP_NAME="OtakTangkas"
APP_ENV=local
APP_KEY=base64:...  # Generated by artisan key:generate
APP_DEBUG=true
APP_TIMEZONE=Asia/Jakarta
APP_URL=http://localhost:8000
APP_LOCALE=id
APP_FALLBACK_LOCALE=en

# Database
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=otaktangkas
DB_USERNAME=root
DB_PASSWORD=your_password

# Pusher (Real-time)
BROADCAST_CONNECTION=pusher
PUSHER_APP_ID=your_app_id
PUSHER_APP_KEY=your_app_key
PUSHER_APP_SECRET=your_app_secret
PUSHER_HOST=
PUSHER_PORT=443
PUSHER_SCHEME=https
PUSHER_APP_CLUSTER=ap1  # Asia Pacific

# Queue (Redis recommended)
QUEUE_CONNECTION=redis

# Cache (Redis recommended)
CACHE_STORE=redis
SESSION_DRIVER=redis

# Redis
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

# Mail (for notifications)
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@otaktangkas.com"
MAIL_FROM_NAME="${APP_NAME}"

# Filament (Admin Panel)
FILAMENT_DOMAIN=admin.otaktangkas.test
```

### Step 5: Database Setup

```bash
# Create database
mysql -u root -p
CREATE DATABASE otaktangkas CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

# Run migrations (will be created in Phase 1)
php artisan migrate

# Seed database (will be created in Phase 1)
php artisan db:seed
```

### Step 6: Redis Setup (Optional but Recommended)

**On Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install redis-server
sudo systemctl start redis-server
sudo systemctl enable redis-server

# Test Redis
redis-cli ping
# Should return: PONG
```

**On macOS:**
```bash
brew install redis
brew services start redis

# Test Redis
redis-cli ping
# Should return: PONG
```

**On Windows:**
```bash
# Use WSL or download Redis for Windows
# https://github.com/microsoftarchive/redis/releases
```

### Step 7: Build Frontend Assets

```bash
# Development build (with hot reload)
npm run dev

# Production build (optimized)
npm run build
```

### Step 8: Start Development Server

```bash
# Terminal 1: Application server
php artisan serve

# Terminal 2: Queue worker
php artisan queue:work

# Terminal 3: Vite dev server (if using npm run dev)
npm run dev

# Terminal 4: Laravel Horizon (optional, for queue monitoring)
php artisan horizon
```

Visit: http://localhost:8000

### Laravel Echo Configuration

**File**: `resources/js/echo.js`

```javascript
import Echo from 'laravel-echo';
import Pusher from 'pusher-js';

window.Pusher = Pusher;

window.Echo = new Echo({
    broadcaster: 'pusher',
    key: import.meta.env.VITE_PUSHER_APP_KEY,
    cluster: import.meta.env.VITE_PUSHER_APP_CLUSTER,
    wsHost: import.meta.env.VITE_PUSHER_HOST || `ws-${import.meta.env.VITE_PUSHER_APP_CLUSTER}.pusher.com`,
    wsPort: import.meta.env.VITE_PUSHER_PORT ?? 80,
    wssPort: import.meta.env.VITE_PUSHER_PORT ?? 443,
    forceTLS: (import.meta.env.VITE_PUSHER_SCHEME ?? 'https') === 'https',
    enabledTransports: ['ws', 'wss'],
    disableStats: true,
});
```

Update `resources/js/app.js`:

```javascript
import './bootstrap';
import './echo';
import Alpine from 'alpinejs';

window.Alpine = Alpine;
Alpine.start();
```

### Broadcasting Configuration

**File**: `config/broadcasting.php`

Ensure Pusher is configured:

```php
'connections' => [
    'pusher' => [
        'driver' => 'pusher',
        'key' => env('PUSHER_APP_KEY'),
        'secret' => env('PUSHER_APP_SECRET'),
        'app_id' => env('PUSHER_APP_ID'),
        'options' => [
            'cluster' => env('PUSHER_APP_CLUSTER'),
            'host' => env('PUSHER_HOST') ?: 'api-'.env('PUSHER_APP_CLUSTER', 'mt1').'.pusher.com',
            'port' => env('PUSHER_PORT', 443),
            'scheme' => env('PUSHER_SCHEME', 'https'),
            'encrypted' => true,
            'useTLS' => env('PUSHER_SCHEME', 'https') === 'https',
        ],
        'client_options' => [
            // Guzzle client options: https://docs.guzzlephp.org/en/stable/request-options.html
        ],
    ],
```

## 🐛 Common Issues & Solutions

### Issue: Port 8000 Already in Use

```bash
# Use different port
php artisan serve --port=8001

# Or find and kill process using port 8000
# On Linux/Mac:
lsof -ti:8000 | xargs kill -9

# On Windows:
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

### Issue: Pusher Connection Failed

1. Verify `.env` credentials are correct
2. Check Pusher app is active
3. Ensure cluster is correct (ap1 for Asia Pacific)
4. Check firewall isn't blocking WebSocket connections

```bash
# Test Pusher connection
php artisan tinker
>>> broadcast(new App\Events\TestEvent());
```

### Issue: Node Modules Not Found

```bash
# Clear node modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

### Issue: Redis Connection Refused

```bash
# Start Redis
# On Linux/Mac:
redis-server

# On Mac with Homebrew:
brew services start redis

# Check if running:
redis-cli ping
```

### Issue: Database Connection Failed

1. Verify MySQL is running
2. Check database name, username, password in `.env`
3. Ensure database exists

```bash
# Create database manually
mysql -u root -p
CREATE DATABASE otaktangkas;
EXIT;
```

### Issue: Permission Denied on storage/

```bash
# Fix permissions (Linux/Mac)
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

# Or use current user
chmod -R 775 storage bootstrap/cache
```
